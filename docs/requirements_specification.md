# Live2D Desktop App 要件定義書

## 1. プロジェクト概要
デスクトップ上にLive2Dモデルを表示し、ユーザーと交流できるマスコットアプリケーション。
背景を透過させ、デスクトップ壁紙の上にキャラクターが直接存在しているような視覚効果を提供する。

## 2. 機能要件

### 2.1 モデル表示機能
- 任意のLive2Dモデル（Cubism 3.0以降）を表示できること。
- 背景が完全に透過していること。
- キャラクターがデスクトップの最前面に表示されること（設定により切り替え可能）。

### 2.2 ユーザーインタラクション
- マウスカーソルの動きに合わせてキャラクターの視線が追従すること。
- キャラクターをドラッグしてデスクトップ上の任意の位置に移動できること。
- 特定の部位（頭など）をクリックした際にリアクション（モーション再生）をとること。

### 2.3 システム制御
- 設定パネル（オーバーレイ）により、以下の調整ができること：
    - モデルの表示スケール（拡大・縮小）
    - モデルの不透明度
- システムトレイ（メニューバー）から以下の操作ができること：
    - ウィンドウの表示/非表示の切り替え
    - 「常に手前に表示」の有効/無効の切り替え
    - アプリケーションの終了

## 3. 非機能要件

### 3.1 対応OS
- macOS (Apple Silicon / Intel)

### 3.2 パフォーマンス
- デスクトップ作業を妨げないよう、CPUおよびメモリ使用量を抑えること。
- 描画がスムーズであること（目標60 FPS）。

### 3.3 拡張性
- 容易にモデルを差し替えられる構成であること。
